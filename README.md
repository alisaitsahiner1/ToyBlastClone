# ToyBlastClone
Cloning Peak's Game Toy Blast. Development still ongoing

Toy Match is a fan-made, educational match-3 puzzle game inspired by Toy Blast by Peak Games.
Match colorful cubes, trigger combos, and clear levels using boosters — all built from scratch for learning purposes!

🎥 Demo Video

Watch gameplay footage here:
👉 ▶️ Watch on YouTube https://youtu.be/77qCep5yaXQ

🎮 Features

Classic Match-3 mechanics with cube matching & clearing

Chain reactions and combo explosions

Booster items (hammer, rocket, bomb, etc.)

Level-based progression system

Star scoring & move limits

UI for both desktop and mobile

Smooth animations and sound effects

Save/load basic game data (PlayerPrefs)

Unity 2022 or later

C#

2D Sprite Renderer & Particle System

ScriptableObjects for level and block data

Unity UI Toolkit (TextMeshPro)

Addressable Assets / SceneManager

🧩 How to Play
Action	Input
Select Block	Left Click / Tap
Match & Clear	Select groups of 3+ same-colored cubes
Use Booster	Click on booster icon
Restart Level	From pause or failure screen
🚀 Getting Started

Clone or download this repository

Open the project in Unity Hub (2022+)

Open the Scenes/MainMenu and click Play

Try editing existing levels or adding new ones in Assets/Levels/
